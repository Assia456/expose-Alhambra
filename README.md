# Proyecto: La Alhambra de Granada

Ce projet est un site web interactif réalisé dans le cadre d'un exposé scolaire sur **La Alhambra de Granada**.

## Fonctionnalités
- **Page d'accueil immersive** avec une présentation en plein écran (*Hero section*).
- **Section Histoire** retraçant les origines et les dates clés (XIIIe siècle, 1492...).
- **Architecture** détaillant les parties principales (Alcazaba, Palacios Nazaríes, Generalife).
- **Galerie interactive** avec des visuels du monument.
- **Quiz de connaissances** pour tester ce qu'on a retenu.

## Technologies utilisées
- HTML5 / CSS3 (Design custom)
- JavaScript (Interactivité et logique du quiz)
- AOS (Animations fluides au défilement)
